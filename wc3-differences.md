# Differences from Warcraft III
{: .no_toc }

What a map script observes in WarMash that differs from real Warcraft III, native by native. A native that is not listed is either believed to match or is missing; see [Native coverage](differences/runtimes-and-coverage.html#native-coverage-and-constants). The status words are explained on the [home page](./).

Compared with Reforged 3.0.1 for Lua maps and 1.29 for JASS maps. "Measured" means checked by a scripted run in real Reforged 3.0.1.
