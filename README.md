# WarMash script API documentation

This repository is the source of the documentation website for the WarMash script API:

https://lufion1420.github.io/warmash-docs/

WarMash is a game engine written in Java that runs Warcraft III maps, including Lua maps. The site records, native by native, which script functions work, which behave differently from the real game, the WarMash-only `Wms` API, launch arguments, test hooks and the changelog.

## How the pages are made

The Markdown pages in this repository are generated from the engine repository (a private repository) by a publish script. **Edits made here directly are overwritten by the next publish.** To suggest a correction, open an issue in this repository describing the page and the fact.

The site is built by GitHub Pages with Jekyll and the [just-the-docs](https://github.com/just-the-docs/just-the-docs) theme.
